# Контекст проекта для Claude Code

Проект: ИИ-агент первой линии техподдержки. Роль агента описана в
`.claude/agents/l1-support.md`, процедуры - в `.claude/skills/`.

## Важно при работе с данными

Поля `category` и `priority` в исходной очереди **проставлены случайно** и не
согласованы с текстом заявки. Источник истины - `description`. Никогда не используй
исходную категорию как эталон для метрик.

## Правила разработки

- Всё, что можно вычислить детерминированно, выносится в `policies/*.yaml`,
  а не в промпт. Промпт - только про понимание текста.
- Любое новое действие агента добавляется как MCP-инструмент, а не как хардкод
  в оркестраторе.
- Каждое решение агента пишется в `data/shadow/audit.jsonl` - на этом журнале
  строятся все метрики.
- Изменения тикетов идут только в shadow-overlay. Прямая запись в mockapi - под
  флагом `LIVE_WRITES=1` и по умолчанию выключена.
